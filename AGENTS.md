# AGENTS.md

## Repository Overview

This is **Shun Yuen's personal GitHub profile repository** (`shyuen/shyuen`). It serves as a public-facing GitHub profile and landing page.

## Project Structure

- `README.md` — Personal introduction displayed on the GitHub profile page. Contains a bio, tech-stack badges, experience highlights, a projects section, certifications, and the embedded GitHub metrics SVG.
- `github-metrics.svg` — Auto-generated SVG graphic showing GitHub activity stats (lines, languages, stars, topics). Regenerated daily via GitHub Actions.
- `.github/workflows/metrics.yml` — GitHub Actions workflow that runs `lowlighter/metrics@latest` on a daily cron schedule to regenerate the metrics SVG.
- `www/` — A simple static site directory containing a basic HTML/CSS page.
  - `www/index.html` — Static HTML page.
  - `www/css/index.css` — Stylesheet for the static page.
- `.nojekyll` — Prevents GitHub Pages from processing the site with Jekyll.

## Tech Stack & Context

- **Static site**: Plain HTML/CSS in the `www/` directory. No build tools, no frameworks, no package manager.
- **GitHub Actions**: Uses `lowlighter/metrics` for automated SVG generation. Requires a `METRICS_TOKEN` secret.
- **GitHub Pages**: This repo is likely deployed via GitHub Pages for the profile README.
- **Personal profile repo**: Changes should be kept simple and intentional. This is a public-facing profile.

## Guidelines for AI Agents

- **Keep it simple.** This is a minimal personal profile repo — avoid introducing unnecessary complexity, build tools, or dependencies.
- **Do not modify `github-metrics.svg` directly.** It is auto-generated by the GitHub Actions workflow. Manual edits will be overwritten.
- **Do not alter the metrics workflow** (`metrics.yml`) unless explicitly asked. It runs on a schedule and is working as intended.
- **Be cautious with `README.md`.** It is the centerpiece of the GitHub profile page. Any changes should be minimal and clearly beneficial.
- **Static content only.** The `www/` directory should remain plain HTML/CSS. Do not introduce JavaScript frameworks or build pipelines here.
- **No new secrets or tokens.** The workflow relies on a `METRICS_TOKEN` secret already configured in the repository settings.

## Common Tasks

- Updating the personal bio or information in `README.md`.
- Making small changes to the `www/` static site (HTML/CSS tweaks).
- Adjusting the metrics workflow configuration (plugins, schedule, timezone).

## Validation

- After editing HTML/CSS, verify the files are syntactically valid.
- There are no automated tests in this repository.
